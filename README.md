# Underwater World

A compact 2D underwater action-platformer built with Godot for CSCI 5499B/5999B Project 1.

## Development

Open `project.godot` in Godot and run the project. Use A/D to move, Space to swim upward, S to dive quickly, and N to pick up or throw a nearby rock.

## Releases

The final GitHub release will include builds for:

- Windows x86
- macOS
- Linux x86
