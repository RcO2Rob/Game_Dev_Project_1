# 第三关：深海神庙

地图宽 21,504 像素（约 18.7 屏），比第二关长 40%。首次探索目标 5～7 分钟，尚需真人试玩校准；熟练速通会更短。

| 路段 | 横坐标 | 内容 |
| --- | --- | --- |
| 神庙花园 | 0～3584 | 入口三颗钻石、台阶与上层奖励路线 |
| 珊瑚通道 | 3584～7168 | 错层跳台、珊瑚装饰和地面战斗，不再包含洋流区域 |
| 漂浮石礁 | 7168～10752 | 横向移动平台、固定石台衔接 |
| 蒸汽遗迹 | 10752～14336 | 六处错峰喷泉，闪烁提示后喷发，可等待或从上方跨过 |
| 静默深沟 | 14336～17920 | 错层窄石台、两段深沟，主跳跃区无敌人 |
| 海洋之心 | 17920～21504 | 最后的战斗、移动平台与高台，进入螺壳完成游戏 |

每段交界有检查点，共五个；首次激活回血并更新复活点。地图中有 26 颗钻石：20 颗位于主路线附近（含入口三颗），6 颗位于高处支路。

商店只在每关终点出现，购物时整关暂停，继续后才进入下一关。界面不使用文字按钮：钻石图标表示价格，剑、心和“心+上箭头”分别表示武器、回血和生命上限，螺壳加右箭头表示继续。2 颗钻石购买并装备石剑，1 颗钻石恢复一格血，3 颗钻石增加一格生命上限并补上一格血，上限五格。余额不足、满血、已持剑或达到上限时禁用对应购买，拒绝购买不会扣费。石剑维持 N 拾取/丢弃、M 攻击、受伤击飞消失的规则。

第一关场景树中包含一个短距离移动石台和一个有预警的间歇喷泉作为教学示范，让玩家在进入第三关前见过这些机制。洋流机制及其教学区域已经移除。

关卡切换会带入当前金币、钻石、生命、生命上限及持剑状态；这是本次游玩的内存记录，不是关闭游戏后的永久存档。第二关终点商店的螺壳箭头进入第三关。直接 F6 启动第三关或完成后重玩，会开始新的一局。

场景内地形与组件均保存为可编辑节点，编辑 `scenes/stage_3.tscn` 即可调整。第三关生成脚本仅用于重新生成初稿，会覆盖第三关手工编辑，勿在人工修改后随意运行；第一、二关地图不参与生成。

验证：`scripts/tools/test_stage_3.gd` 覆盖第二关终点视觉商店、第三关内商店隐藏、余额携带、交易失败不扣费、升级上限、购物暂停、移动平台载人、检查点复活、喷泉时序和第三关终点商店。局部跳跃试跑另验证了 10 组高差、窄台与深沟落点；不代表整关战斗已由真人通关。
