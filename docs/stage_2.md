# 第二关：珊瑚遗迹

地图宽 15,360 像素，约 13.3 屏。首次探索目标 3～5 分钟，熟练速通会更短；时长仍需真人试玩校准。纯地形自动试跑约 83 秒，不包含战斗、拾取、支路和等待泡泡。

| 区段 | 横坐标 | 节奏 |
| --- | --- | --- |
| 入口石阶 | 0～3072 | 安全拾剑区、小规模螃蟹巡逻、逐级跳台，熟悉操作 |
| 泡泡裂隙 | 3072～6144 | 较多裂隙，提前放置石头，金币弧线提示跨越方向 |
| 高低岔路 | 6144～9216 | 连续高台与可选上层路线，钻石奖励额外探索 |
| 遗迹战斗 | 9216～12288 | 螃蟹、海胆、水母错开配置，木桶提供金币奖励 |
| 终点挑战 | 12288～15360 | 704 像素精准跳跃深沟，随后进入安全路段和终点螺壳 |

四个检查点位于各段之间，首次激活会恢复生命值并更新复活位置；走回旧检查点不会覆盖较新的进度。每段入口都有剑，裂隙前有石头。主线不要求借助随机泡泡升降，五颗钻石均有固定跳台路线。

13 处普通裂隙均宽 96 像素；泡泡基础间隔随机 4～9 秒，偶尔更长。第五段开头另有一个 704 像素宽的精准跳跃深沟，中间由四块 64 像素宽、带高低差的小石块分隔。金币标出落点，最高石块上方放置一颗钻石。第四个检查点就在挑战前。台阶单次升高不超过 96 像素，可选支路平台通常相差 128 像素。

关卡额外配置 8 只主动型龙虾。龙虾在没有发现角色时进行短距离巡逻；当角色处于同一高度、距离足够近且中间没有地形遮挡时，龙虾会转向追赶，并在近距离使用双钳攻击。龙虾避开精准跳跃区、平台边缘和检查点。角色持剑受到伤害时，剑会被击飞、短暂显示后消失；按 N 主动丢剑仍会留下可重新拾取的剑。装饰放在后层，没有碰撞。

在 Godot 打开 `scenes/stage_2.tscn` 后按 F6 可单独试玩；第一关末尾的螺壳也会进入本关。到达终点后先出现纯图形钻石商店，点击螺壳箭头进入第三关，并携带当前金币、钻石、生命和武器。

所有地形、道具、敌人都是保存进场景的可编辑节点。日常修改直接在 Godot 中进行。`scripts/tools/build_stage_2.gd` 仅供重新生成初稿，运行会覆盖第二关的手工编辑；运行时不会自动生成地图。
